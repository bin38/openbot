# Grok Bot 功能参考与本地实现

核对日期：2026-11-04。依据官方文档归纳行为，不复制其实现或专有连接器后端。

| 官方功能 | OpenBot 当前实现与本轮改进 |
| --- | --- |
| 持续任务、可检查的结果与 Library | 保留原有助手、工作区、任务、计划和记忆；增加 API 任务与产物历史，最近 50 条可按端点筛选。打开结果不重新生成，未完成任务可显式刷新。 |
| 从对话连接应用 | 本机 Codex 可以查模板、创建禁用的 API 渠道草稿。用户在设置中完善凭据并启用；模型不读取保存的密钥。 |
| 观察电脑工作、人工接管后交还 | 对话侧栏保留 E2B 预览、接管、交还与关闭清理。人工控制期间自动预览和助手电脑操作受控制锁约束。 |
| 手机继续查看任务、回答和审批 | 恢复手机连接入口，保留原二维码、设备列表和撤销流程。只有自建账号与已发布主机就绪时才提供配对；当前本地模式明确显示配置条件。 |
| 跨会话取回文件 | API 产物可以直接保存或交付聊天附件；已缓存文件不因端点停用、改配置或删除而丢失访问入口。旧记录没有时间戳时明确标记，不推测时间。 |
| 清晰的执行状态 | 区分完成、处理中、失败和结果未知。请求中断后的未知结果不会自动重发；本地历史查询也不重新执行 API。 |

本轮另外修复了本机服务器设置误读账号服务、条件属性导致的界面冻结，以及 API 对话框开关和下拉菜单的问题。
设置与云电脑面板加入局部错误边界和手动重试入口，恢复面板时不重置工作区或对话。

## 保留的区别与条件

- Grok Bot 使用其托管的云电脑和运行服务。这里的模型仍由运行 OpenBot 的主机驱动；本机 Codex 不会因接入 E2B 而在电脑关机后继续运行。持续执行需要常开主机。
- 当前 E2B 绑定按助手隔离，没有改成 Grok 的账号共享电脑，以免扩大文件和登录信息的共享范围。
- 本轮不改变原手机通信协议，也没有进行手机应用签名发布、真机配对或公网部署。自建二维码流程与原站邮箱登录是不同入口。
- 专有邮箱、X 平台账号服务和闭源连接器不会被当作已迁移。X、飞书及其它 API 仍使用用户自己授权的账号和权限。
